# FashionHub — Local Fashion Store Demo

Client-facing catalogue concept for a local kids, tween and teen clothing shop.

### Included
- Fashion-first editorial homepage
- Girls, Boys, Teen and Traditional collections
- Real-model catalogue imagery
- New-in filters
- Quick-view product modal
- Style enquiry flow
- Store visit section
- Responsive mobile navigation

### Before client delivery
Replace the demo address, phone/WhatsApp, timings, logo and catalogue images with the real shop details. The enquiry form can be connected to WhatsApp or a backend later.

Built with Vite + vanilla JavaScript + responsive CSS.
